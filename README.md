# شعر و تال غفور

وب‌اپلیکیشن/PWA راست‌چین برای مدیریت شعر، راگ، تال، فایل‌های صوتی و تصویری و تمرین موسیقی.

## اجرا در GitHub Pages

1. تمام محتویات این پوشه را در ریشه یک repository قرار دهید.
2. در GitHub از Settings → Pages، منبع انتشار را روی branch موردنظر و پوشه `/root` بگذارید.
3. برنامه از مسیرهای نسبی (`./`) استفاده می‌کند و برای GitHub Pages با repository path طراحی شده است.
4. برای نصب PWA در iPhone/Android، سایت باید با HTTPS باز شود.

## فایل‌ها

- `index.html` — رابط و منطق اصلی برنامه
- `manifest.webmanifest` — مشخصات PWA
- `sw.js` — کش آفلاین فایل‌های اصلی
- `photo.jpg` — عکس شخصی ارسالی
- `icon.png`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `favicon.png` — آیکن‌ها
- `README.md` — راهنما

## ذخیره‌سازی

داده‌های ساختاری و Blob رسانه‌ها در IndexedDB ذخیره می‌شوند؛ LocalStorage فقط برای یک عکس سفارشی استفاده می‌شود. بنابراین بعد از refresh و بازگشایی مرورگر، داده‌ها تا زمانی که فضای ذخیره‌سازی سایت پاک نشود، باقی می‌مانند.

## رسانه

مرورگر فایل را با `<audio>` یا `<video>` پخش می‌کند. MP3/M4A/AAC/WAV/OGG و فرمت‌های ویدیویی متداول در صورت پشتیبانی مرورگر قابل پخش هستند؛ FLAC و برخی MOV/Codecها ممکن است در یک مرورگر خاص پشتیبانی نشوند و برنامه خطای پخش را نشان می‌دهد.

## Apple Notes

دسترسی مستقیم وب‌سایت به پایگاه داخلی Apple Notes ارائه نمی‌شود. مسیر عملی:
- Apple Notes → Share → Save to Files، سپس واردکردن TXT/Markdown/CSV/JSON
- یا Copy/Paste متن داخل برنامه

## پشتیبان

JSON شامل داده‌های ساختاری، ارتباط‌ها و تنظیمات است؛ Blobهای صوتی/تصویری داخل JSON قرار داده نشده‌اند تا از بزرگ و شکننده‌شدن خروجی جلوگیری شود. دکمه «فهرست رسانه‌ها» فقط فهرست رسانه‌ها را صادر می‌کند و عمداً ادعا نمی‌کند که خود فایل‌ها در آن بسته هستند.

## محدودیت مهم iOS

وب‌اپ نمی‌تواند ادامه پخش را پس از «کشته‌شدن کامل» فرایند Safari/PWA تضمین کند. Media Session و HTML5 audio/video تا حد قابلیت واقعی مرورگر استفاده شده‌اند. پخش پس‌زمینه در شرایطی که iOS/Safari اجازه دهد ممکن است ادامه پیدا کند.

## تست‌های ساختاری انجام‌شده

- وجود تمام فایل‌های اصلی و آیکن‌ها بررسی شده است.
- Manifest و Service Worker با مسیرهای نسبی ساخته شده‌اند.
- HTML از نظر وجود بخش‌های اصلی، IndexedDB، `<audio>` و `<video>` بررسی شده است.
- فایل رسانه‌ای نمونه داخل بسته قرار داده نشده؛ بنابراین «آزمایش پخش MP3 واقعی» بدون فایل MP3 واقعی از کاربر قابل ادعا نیست. برای تست واقعی، یک MP3 را داخل برنامه اضافه و دکمه ▶ را لمس کنید.
